Release model

Built for fixed reference points, not mystery files.

Downloads on this page are versioned intentionally. The app line is meant for installer-style releases, while the source line stays commit-based so code, documents, and architecture discussion can be read together without ambiguity.

How versioning works

Installer builds and commit snapshots

The page supports two release patterns: installer-style app builds for the GrowNet Lab App, and fixed repository snapshots for the source line. Both are meant to be updated from a single manifest file.

App line grownet-lab-app-VERSION.ext
Source line grownet-source-YYYY-MM-DD-COMMIT.zip

Why this page exists

One place for source and tooling downloads

The Docs page remains the reading path. The Downloads page is the artifact path: the GrowNet Lab App for runnable builds, and source snapshots for fixed-code reference points.
