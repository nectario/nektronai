Release model

Built for fixed reference points, not mystery files.

Downloads on this page are versioned intentionally. Each source release corresponds to a specific repository commit so the code, documents, and architecture discussion can be read together without ambiguity.

How versioning works

Commit-based snapshots

The current naming scheme uses the publication date plus the underlying commit hash. That makes it easy to refer to a specific version in discussion, testing, or implementation notes.

Pattern grownet-source-YYYY-MM-DD-COMMIT.zip
