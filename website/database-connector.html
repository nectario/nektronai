USEFUL ACCESS. CLEAR BOUNDARIES.

Built for investigation.
Careful with your data.

Access follows the database account you authorize. You stay in control of what the connector can reach.

Read-only database access

Restricted database credentials and engine-specific query controls work together. Relational queries are limited to permitted reads; MongoDB pipelines cannot write documents. The connector does not update your records.

Credentials outside the chat

Connection credentials are stored encrypted and are not returned to ChatGPT. Authorized query results are shared with ChatGPT to answer your questions.

Bounded queries

Time, concurrency, row, and response limits keep requests controlled. Truncated results and unknown coverage are identified.

Network access stays explicit

Verified TLS is required. The connector does not open database firewalls; private networks may need administrator setup.

SUPPORTED ENGINE PROFILESMySQL · PostgreSQL · SQL Server · Oracle · MongoDB

Supported profiles: MySQL 8.4.5, PostgreSQL 17, SQL Server 2022, Oracle 19 and Oracle Free 26ai (server major 23), and MongoDB 8. Use restricted read-only credentials and verified TLS. Private networks may require administrator setup.

A FEW GOOD QUESTIONS

Before you connect.

Need a hand with your database?
Talk to Nektron ↗︎

What database details do I need?

Choose your engine and provide the host, approved port, database name, username, and password—or a connection URL without extra options. Oracle uses a service name and table owner; PostgreSQL and SQL Server can specify a schema. Use a dedicated read-only account with permitted table or collection access and verified TLS. Network access must already be available or arranged by your administrator.

Can it change or delete my data?

Relational tools execute policy-validated read-only SQL. MongoDB uses bounded aggregation pipelines without JavaScript, cross-collection lookup, output, or merge stages. Database writes are rejected. The service does maintain connection settings, operational audit metadata, and temporary concurrency records outside your database.

Can I use my existing account access?

Yes. Sign in with your Nektron account to use its existing database allowance. This page provides setup and account information; it does not initiate subscriptions or upgrades.

What happens if my connection allowance changes?

Your first saved database remains available under Free. Additional saved configurations may be unavailable when they exceed your current entitlement. Customer database records are not deleted.

Which databases and devices are supported?

Supported database profiles are MySQL 8.4.5, PostgreSQL 17, SQL Server 2022, Oracle 19 and Oracle Free 26ai (server major 23), and MongoDB 8. SQL and document queries have engine-specific limits. Public directory availability is still in preparation; iPhone availability is not yet verified.

How should I judge an answer?

Check the returned records, result limits, and source context. Separate queries are separate snapshots, and AI interpretations can be wrong. Verify important conclusions against your source data.
